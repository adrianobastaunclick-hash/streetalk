# PROJECT BLUEPRINT // STREETALK REALTIME ECOSYSTEM

## 1. Visual & Cinematic Layer (FrontEnd-Cinematic-Dev + UIUX-Design-Virtuoso)
- **Viewport**: Scena 3D Three.js r128 con asfalto deformato a onde sinusoidali e 800 particelle neon fluttuanti responsive a mouse e touch.
- **Framerate Target**: 60-120 FPS garantiti con dynamic device pixel ratio.
- **Design Language**: Dark Street Neo-Brutalist (#0a0b0e, accento neon #ff5500, contrasto elevato, font Syne e JetBrains Mono).
- **Sensory Feedback**: Web Audio API procedurale nativo per sweep sub-bass 808, blip di ricezione e pop su reazioni emoji (zero file MP3 esterni).

## 2. Logic & Realtime Engine Layer (Game-Mechanics-Engine + AI-Backend-Engineer)
- **Realtime WebSocket**: Node.js + Socket.io su porta dinamica e deploy attivo su Render (`https://streetalk.onrender.com`).
- **RAM Volatile Architecture**: Code FIFO separate per mood (cazzeggio, sfogati, flirt) e filtraggio genere interamente in-memory. Zero database di transito.
- **Pairing Deterministico**: Scambio simultaneo e crittograficamente isolato dei segreti e assegnazione pseudonimi urbani univoci.
- **Timer & Life-cycle**: Conto alla rovescia di 180s con estensione bilaterale (+300s) e deallocazione istantanea allo skip o al disconnect.

## 3. Resilience, Security & Audit Layer (Smart-Contract-Auditor + Self-Correction-Auditor)
- **Sanitizzazione Input**: Validazione rigida dei segreti (3-90 caratteri, rigetto <script>, URL http/https e numeri telefonici).
- **DOM Safety**: Neutralizzazione XSS garantita su messaggi e segreti prima del rendering.
- **Volatile Memory Audit**: Azzeramento provato di Users, Rooms, Queues e RateLimits alla disconnessione (zero ghost instances).
- **Technical SEO**: Robots.txt, sitemap.xml, Schema.org JSON-LD (WebApplication, Organization, HowTo, FAQPage 8 items) e verifica Google Search Console.
- **Test Baseline**: 63/63 test superati con successo in `tests/autonomous-suite.js`.
