MANIFESTO TECNOLOGICO // ARCHITETTURA FORENSE ZERO-LOG IN RAM

La maggior parte delle piattaforme web promette l'anonimato ma memorizza gli indirizzi IP, gli orari di connessione e i metadati su dischi rigidi permanenti. STREETALK è ingegnerizzata con una filosofia opposta:

1. Zero Disk Storage: Nessuna tabella su database conserva i messaggi della chat; vivono unicamente nella memoria RAM volatile del processo Node.js.
2. Istant Deallocation: Quando clicchi "Salta" o chiudi la scheda, la stanza e le strutture dati vengono rimosse dalla memoria in <1ms.
3. Anti-XSS Sanitizer: Qualsiasi tag HTML, script o tentativo di iniezione viene neutralizzato alla sorgente tramite DOMSafetyFilter.
4. Zero Cookie Profilanti: Nessun tracciatore Google Analytics o Facebook Pixel. La tua identità digitale rimane inviolata.
