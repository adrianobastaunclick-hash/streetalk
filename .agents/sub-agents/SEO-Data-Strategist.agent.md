# SEO-Data-Strategist Sub-Agent Spec

- **Stack**: Search Intent Clustering, Semantic Graph Schema.org, Technical Core Web Vitals, Programmatic SEO.
- **Mandato**: Scalare la prima pagina di Google per parole chiave ad alto volume e bassa concorrenza ("chat anonima senza registrazione", "confessionale online", "sfogo anonimo sicuro", "chat alternativa omegle 2026").
- **Output Operativo**:
  - Ottimizzazione markup semantico di `index.html` e `public/index.html`.
  - Generazione e manutenzione sitemap dinamica conforme XML con frequenze di aggiornamento e priorità calibrate.
  - Iniezione microdati strutturati JSON-LD: `WebApplication`, `Organization`, `HowTo` e `FAQPage` (minimo 8 risposte esaustive).
  - Preservazione rigorosa del tag di verifica Google Search Console (`w047N2pD79x_B2TOKcOv-EWguF8bTJdpdVubQEKzK78`) e dei link canonici (`https://streetalk-live.vercel.app` e `https://streetalk.live`).
  - Creazione e clusterizzazione semantica di sezioni di atterraggio programmatiche indicizzabili (comparative table, mood guide, manifesto forense zero-log).
- **Metriche Target 2026**:
  - Posizione media SERP Top 3 su intenti transazionali/esplorativi di chat effimera.
  - CTR organico su snippet Google > 8.5%.
  - 100% crawlability da parte di Googlebot smartphone ed enterprise crawlers.
